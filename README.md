# Acel & Haikal Sanctuary - Couple Ecosystem
Private custom couple email, shopping tracker, love letters, and ecosystem management system.

## Project Structure
- `backend/`: Node.js Express/Fastify API, Mail Ingestion & Receipt Parser Engine, SQLite Database.
- `frontend/`: Modern White + Apple Liquid Glass Webmail & Couple Portal (Vite + React + CSS).
- `mobile_app/`: Flutter Cross-Platform Application (Android & iOS iPhone 15).
- `cloudflare/`: Cloudflare Email Worker for seamless email forwarding to webhook.
- `docker/`: Dockerfile & Pterodactyl deployment configuration.
